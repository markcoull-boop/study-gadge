# Study Gadge

Nat 5 revision web app. Open index.html, or host this folder and add it to the home screen.

## Put it on GitHub Pages
1. Create a new public repository, e.g. `study-gadge`.
2. Upload everything in this folder (index.html, sw.js, manifest.webmanifest and the icon PNGs) to the root of the repo.
3. Settings > Pages > Build and deployment: Source "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. After a minute it's live at https://<your-username>.github.io/study-gadge/

## Add to the home screen (iPhone)
Open the link in Safari, tap Share, then Add to Home Screen.
Open it once with internet so it saves itself for offline use.

## Updating
Upload the new files over the old ones. The app picks up the new version the next time it's opened with internet (sometimes it takes a second open).
